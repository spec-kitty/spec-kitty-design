## Blocking finding 1 — HIGH: unresolved state metadata can publish internal state

`scripts/normalise-manifest.mjs:234-261` treats `state` as true only when its initializer is the
literal `true`. Any other property-assignment initializer is silently treated as false. As a
result, this valid TypeScript shape is normalized as a public property-only field even though the
runtime value makes it internal state:

```ts
const isInternal = true;

export class SkStateUnresolved {
  static properties = {
    structured: { attribute: false, state: isInternal },
  };

  structured: ReadonlyArray<string> = Object.freeze([]);
}
```

An isolated direct normalizer run exited zero and reported `1 property-only field(s), 1
empty-array reset(s)`; the resulting member carried both
`x-spec-kitty-property-only: true` and `x-spec-kitty-property-reset: "empty-array"`. The analogous
`attribute: shouldObserve` case also exited zero with no marker rather than failing closed. These
are unprovable AST options, not evidence that a field is safely public or safely observed.

This contradicts T001/T002's fail-loud requirement for unsafe or unresolvable AST shapes and the
locked rule that internal `state: true` must never cross the manifest-to-React boundary.

Required remediation:

1. In `inspectOptions()`, classify literal boolean/string attribute and literal boolean state
   options explicitly. Fail with an actionable source location whenever an `attribute` or `state`
   option that affects property-only classification cannot be proven from its AST value. Do not
   assume an unresolved `state` value is false.
2. Add direct normalizer probes for unresolved `state` and unresolved `attribute` initializers in
   the supported `static properties` and decorator paths. The internal-state-shaped probe must
   fail rather than receive the property-only/reset markers.
3. Re-run the existing marker/state/unsafe-AST probes, wrapper and manifest selftests, generated
   browser fixture, full typecheck/quality/test gates, and production CEM/React stability checks.
