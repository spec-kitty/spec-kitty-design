Full changelog

This release replaces the legacy build pipeline with a incremental, content-addressed cache that skips unaffected packages entirely, cutting the median CI build time from eleven minutes to under three. It also fixes a race condition in the file watcher that occasionally dropped change events on network filesystems, adds a new diagnostic command for inspecting the dependency graph, and upgrades the underlying bundler to its latest major version, which required updating every plugin configuration across the monorepo.
